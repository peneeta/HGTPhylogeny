## Files
* [[Data]] - contains bacterial metadata, 16S, and gyrA fasta sequences (rpoD is present also but was not used in the analysis). The subset 16S and gyrA are paired - they contain the same species in both files for phylogenetic tree comparisons.
* [[query_entrez.ipynb]] - example query for how the CDS data was obtained from the NCBI database.
* [[intragenic_conflict]] - contains the treefiles constructed using a sliding window approach described in Smith et al. (https://academic.oup.com/mbe/article/37/11/3380/5870841). Shell commands used to generate these outputs are provided in [[intragenic_conflict.sh]]
